# MetalQC · 双链路智能质检辅助系统

《人工智能应用实践》课程项目，山东大学人工智能学院。团队：刘孟霄、李丰润、侯亚琳。

面向金属零件多品种、小批量场景，把本地感知、灰区视觉分析、自动归档、人工复核及候选迭代接成完整作业流程。当前支持螺母、螺丝和金属网格；螺丝内部匹配视图，未覆盖的外观转复核。

## 当前功能

- **检测**：单图、可恢复后台批次、评分与热图；低/灰/高风险分流，灰区按需调用 qwen3-vl-plus + RAG。
- **作业处置**：满足适用性、门槛与版本权限才自动归档；不确定、边界、异常和周期抽查进入人工任务。
- **复核闭环**：保存最终标签与批准状态，去重和测试封存检查后才用于训练或阈值校准；候选评估、人工应用、回退分开执行。
- **追溯**：检测档案、PDF、CSV、上下文AI助手和质效统计。
- **界面**：四个日常入口；研发设置分为检测配置、样本与建库、研究资料，按需加载。

自动归档或隔离是软件状态，不等于实物放行或报废。当前头部辅助模型仍全部人工复核，螺杆研究候选未获得自动处置权限。

## 本地运行

Python 3.10+，无需GPU；完整检测需要自备模型和数据，单独克隆源码不能复现已部署模型结果。

```bash
python -m pip install -r requirements.txt
# Windows PowerShell：填自己的密钥，切勿提交真实值
$env:DASHSCOPE_API_KEY = "your-own-key"
# Linux/macOS：export DASHSCOPE_API_KEY="your-own-key"
```

1. 将 CLIP ViT-B-16 权重放在 `weights/CLIP-ViT-B-16-open_clip_model.safetensors`。
2. 按来源许可取得数据，放入 `data/`。通过产品接入导入、建库、校准并执行资格评估；历史实验脚本在 `src/experiments/`。
3. `results/perception/banks/products.json` 是已跟踪的配置元数据示例，引用的模型数组、记忆库和报告不随Git分发。使用与自己生成的产物匹配的配置，不要将示例阈值直接套到新产品。
4. 启动：

```bash
python -m uvicorn web.server:app --app-dir src --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000 。没有配置VLM密钥或模型产物时，对应能力不可用，需要先完成配置。

历史研究脚本部分保留原工作区路径；复现前核对输入、输出与冻结协议，避免直接重跑到生产结果目录。
