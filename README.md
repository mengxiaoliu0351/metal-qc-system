# 金属表面缺陷双链路门控智能质检辅助系统

> 《人工智能应用实践》课程项目 · 山东大学人工智能学院
> 团队：刘孟霄、李丰润、侯亚琳

## 项目简介

面向金属零件多品种、小批量检测场景，提供图像检测、灰区 AI 辅助复核、人工核验、报告追溯和候选模型评估。自动归档与隔离均为软件作业状态，不等于产线最终合格签发或物理判废。

## 当前实现

1. 选择产品并上传图片，系统使用该产品的感知配置输出图像级分数与局部热力图。
2. 每产品双阈值将样本分为低风险、灰区和高风险；仅灰区调用 VLM 与知识检索。
3. 作业策略把明确满足门槛的结果自动归档或隔离，把灰区、临界、图像异常等情况转入人工复核，并对自动结果抽查。
4. 人工核验保存真实标签；只有经批准且通过去重、冻结分区排除的样本才能进入候选评估。候选发布和回滚均由人工操作。

网站支持单图与批量检测、AI 助手、历史记录、统计、PDF 报告和 CSV 导出。公网演示部署见 [部署说明](deploy/README.md)。

### 感知方法的边界

最初的 CLIP 局部特征基线仅用正常样本建库，用于异常评分与热力图。当前三产品演示配置在图像级判断上使用了带标签的训练数据：螺母、螺丝使用冻结 CLIP 特征加监督二分类器，网格融合原异常分数与监督分数；局部正常库继续用于热力图。因此不能把当前整套判定称为完全零样本。新产品需要单独建库、校准，已有产品分类器不能直接跨产品使用。

知识检索目前使用标明来源的教学知识卡及官方标准目录链接；没有标准原文时不提供伪造页码或尺寸限值，AI 答复仅供人工参考。

## 阶段验证

| 项目 | 结果 | 口径 |
| --- | --- | --- |
| 历史螺母异常检测 | 115 张测试图，AUROC 98.68%，准确率 111/115 | 原 CLIP 局部异常检测，正常 22 张、缺陷 93 张 |
| 本地三产品二分类对照 | 同批 88 张留出图，原基线 74/88，当前方案 83/88 | 当前方案含缺陷标签训练；未计 VLM、人工复核或拒判 |
| 系统回归 | 42 项自动化测试通过 | 覆盖检测路由、复核、迭代与接口等功能 |

88 张图片来自已使用过的公开数据重新划分，不是新增外部盲测。当前方案仍有 4 张漏检和 1 张误报；完整人机流程和真实产线效果尚需独立验证。详见 [感知准确率优化报告](docs/感知准确率优化报告.md)及[选择性复核与答辩验收说明](docs/选择性复核与答辩验收说明.md)。

## 环境要求

- Python 3.10+（推荐 conda 环境）
- **无需 GPU**：CLIP 小模型 CPU 可跑；VLM 走云端 API
- 依赖见 `requirements.txt`

```bash
pip install -r requirements.txt
```

## 配置（队友必做）

### 1. VLM 密钥（不要写进代码）

在 [阿里云 DashScope](https://dashscope.aliyun.com) 申请自己的 API Key，用环境变量配置：

```bash
# Windows PowerShell
$env:DASHSCOPE_API_KEY = "你的key"
# Linux / macOS
export DASHSCOPE_API_KEY="你的key"
```

代码从环境变量读取，仓库里的 `src/config.py` 只有占位符，**不要把真实 key 提交到 git**。

### 2. CLIP 模型权重

将 `CLIP-ViT-B-16-open_clip_model.safetensors` 放到 `weights/` 目录。权重与训练出的产品分类器不随 Git 仓库分发；仅克隆源码不能直接运行完整检测。

### 3. 数据与建库

数据集（MVTec-AD）因版权和体积不随仓库分发。需要某产品时，按 `data/mvtec/<产品>/train/good/` 组织合格件图片，运行 `src/experiments/` 下的建库脚本（如 `add_screw.py`、`add_grid.py`）生成记忆库与阈值，配置写入 `results/perception/banks/products.json`。

## 运行

```bash
cd src
uvicorn web.server:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000 。

## 目录结构

```
├── src/
│   ├── config.py            # 配置（路径自动定位，key 走环境变量）
│   ├── perception/          # 局部异常检测与图像级判别
│   ├── gating/              # 三区间门控
│   ├── cognition/           # VLM 与知识检索
│   ├── review/              # 选择性复核、反馈与迭代
│   ├── web/                 # FastAPI 后端与前端
│   ├── interface/           # 报告与 PDF
│   └── experiments/         # 建库、校准和评估脚本
├── deploy/                  # 云端部署与验收
├── tests/                   # 自动化回归
├── docs/                    # 实验记录与使用说明
├── weights/                 # 模型权重（不入库）
├── data/                    # 数据集（不入库）
└── results/                 # 记忆库、历史、结果（不入库）
```

## 协作约定

- 不要提交权重、原始数据、运行历史、`.preview/`、`runtime.env` 或真实 API key；已跟踪的产品配置文件只保存元数据，不包含模型数组。
- 提交前运行 `python -m unittest discover -s tests -p "test_*.py"`。
- 演示服务器当前免密码并包含管理功能；长期公开使用前需要为人工复核和模型发布增加访问控制。
