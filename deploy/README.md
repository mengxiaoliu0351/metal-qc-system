# 阿里云完整演示系统

适用于香港 Ubuntu 22.04、2核4GB实例。正式入口为 **https://metalqc.online/**，`https://www.metalqc.online/` 也指向同一系统；原免费演示网址 **https://metalqc.8-210-4-196.sslip.io/** 和公网IP入口 **https://8.210.4.196/** 保留备用。无需账号密码，打开紫色首页后点击“进入检测工作台”即可使用完整系统，包含工件检测、批次检测、人工复核、检验档案、模型迭代、统计和AI助手。域名的 A 记录指向当前公网 IP `8.210.4.196`；服务器公网IP变更时需同步更新解析。

当前按负责人要求设置为无密码公开演示，共享同一个工作区，包含人工复核、候选评估与模型发布功能。

## 入口与加密

- HTTP 80 自动跳转 HTTPS 443。Caddy自动管理 `metalqc.online`、`www.metalqc.online` 和免费网址的域名证书；原IP入口使用 Let's Encrypt 公网IP证书及 `shortlived` 自动续期。证书数据保存在 `caddy_data` 卷，不能随意清除。IP直接访问需要 `default_sni`。
- 安全组放行TCP 80/443。应用8000不映射宿主机；维护入口18000仅绑定服务器环回地址。
- 本机运行 `powershell -ExecutionPolicy Bypass -File deploy/open-admin.ps1`，可经SSH维护通道打开 `http://127.0.0.1:18000/`。普通演示直接用HTTPS地址即可。
- 当前 `DEMO_PASSWORD_REQUIRED=0`，不显示登录或退出按钮；旧 `/login` 地址自动返回首页。以后如需恢复演示登录，可设置为1，保留原有账号配置。
- 服务器 `runtime.env` 为600权限，保留原API密钥和内部管理令牌；不进入镜像、部署包或浏览器。

## 反馈与迭代

现行作业规则详见 [自动归档与周期抽查说明](../docs/自动归档与周期抽查_20261103.md)：符合自动处置门槛的低、高风险样本直接作系统归档或疑似缺陷隔离；灰区经 VLM+RAG 深度分析且证据满足规则时自动分类，其余转人工。质效分析页可设置每日或每周及目标抽查比例，抽查任务和例外共用人工复核队列。自动归档不执行物理放行或报废。

“结果基本正确”保存意见；“结果有误，标记复核”另外标记待核验，并保留困难样本。两者均不生成真实标签、不训练、不改变阈值。

人工复核页可筛选“反馈标记待复核”。检验人员核对图像、提交真实标签，并明确批准用于迭代后，样本才可用于候选训练或独立阈值校准。冻结测试图片依据图像内容排除回流；没有新增校准样本时阈值校准会拒绝执行。

模型迭代使用现有CLIP和正常库，共享特征提取锁，不重复加载第二套主干。评估候选模型、发布、回滚是三个独立操作。候选通过评估也不会自动上线。当前被冻结的三产品图片子集及对应特征缓存已经上传，原始本机历史不迁移。

## 资源

- 一个应用进程、CPU版PyTorch、2线程；最多3个检测/助手请求同时处理或等待，推理与迭代特征提取使用同一把锁。训练期间检测可能等待。
- 应用内存上限3GB，内存与交换空间合计上限4GB；主机准备2GB swap。
- 图片上限10MB/2000万像素，代理请求体12MB；AI输出最多1024 token，模型API单独计费。
- 完整演示工作区不使用旧匿名公开入口的每日20/60次配额。

## 更新与运维

服务器目录 `/opt/metalqc`。更新前备份 `results`、`runtime.env` 和Caddy数据卷。不要用本机结果目录覆盖云端复核记录。

```bash
cd /opt/metalqc
docker compose -f deploy/compose.yaml ps
docker compose -f deploy/compose.yaml logs --tail=80 app proxy
docker compose -f deploy/compose.yaml up -d --build
```

新部署先运行 `build_bundle.py` 生成程序/模型参数包，再运行 `build_benchmark_bundle.py` 打包冻结评估数据。权重单独上传。服务器首次运行 `prepare_demo_login.py` 生成演示账号；已存在的密钥、令牌和演示账号不覆盖。

外部验收：本机 `python deploy/verify_unified.py`（默认无密码；设置 `VERIFY_LOGIN=1` 可验收密码登录模式）。隔离训练验收：将 `verify_iteration.py` 通过标准输入交给应用容器的Python执行；它使用临时结果目录，不发布模型、不写生产标签。`smoke_cloud.py` 是旧匿名部署的验收脚本，不适用于现在的登录入口。

停止容器不会终止ECS计费；结束演示后先备份数据，再按控制台规则处理实例。
