# 演示服务器按需运行

当前项目按短期演示使用服务器：日常本地开发，云端在测试、彩排及答辩期间开启。

1. 停机前备份运行记录、模型与配置、容器内实际代码以及Caddy数据卷。备份放在私有位置，不能提交GitHub。
2. 在ECS控制台停止实例时选择**节省停机模式**。停止容器、退出SSH或在操作系统内关机不能代替ECS计费模式操作。
3. 节省停机停止计算资源计费，云盘等保留资源继续计费，免费额度有效期不会延长。不要把“停止”与“释放实例”混淆。
4. 再次启动时检查公网IP；若已变化，更新域名的`@`和`www`两条A记录。旧IP直连和旧sslip入口不保证有效。
5. Docker守护进程应开机启动，应用与代理使用`restart: unless-stopped`。启动后检查HTTPS、检测、AI助手、复核及PDF，按需检查Compose日志。

节省停机可能遇到重启时计算资源库存不足，因此答辩前提前3～5天恢复并彩排，同时保留本地和离线备用。

计费与资源回收规则：https://help.aliyun.com/zh/ecs/user-guide/economical-mode
