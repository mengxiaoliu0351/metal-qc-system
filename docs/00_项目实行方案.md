## 一、项目概况

### 1. 基本定位



* **题目**：面向金属表面缺陷的双链路门控智能质检辅助系统（《人工智能应用实践》课程）

* **场景**：中小机械加工厂金属零件多品种小批量离线抽检

* **定位**：人在回路的质检辅助工具，不替代人工最终质量判定

* **技术边界**：底层视觉模型、语言模型、RAG 框架均采用开源成熟组件；创新集中在**应用架构设计、场景工作流落地、工程实现**层面

* **核心卖点**：

1. 置信度门控双链路调度（快链路省时间、慢链路保精度）

2. 少样本免训练换产（仅需 10-20 张正常样本建库）

3. 引用 ID 可溯源校验（结论绑定标准原文与页码，错误可识别）

## 二、系统总体架构（四层一底座）



```
数据输入层（缺陷图片 / 正常样本 / 标准文档）

&#x20;     ↓

感知检测层（WinCLIP 零样本异常检测 → 像素级热力图 + 全局异常分数）

&#x20;     ↓

门控路由层（阈值 = 中位数 + 1.5×MAD；分数≥阈值→快链路，<阈值→慢链路）

&#x20;     ↓

双链路执行层

├── 快链路：直接输出缺陷位置 / 异常等级 / 热力图（2-3秒）

└── 慢链路：裁剪缺陷区 → VLM 描述 → RAG 标准检索 → 引用ID校验 → 完整报告（20-30秒）

&#x20;     ↓

应用交互层（界面 / 报告导出 / 历史记录 / 人工复核入口）

&#x20;     ↓

知识库底座（标准片段库 + 引用ID + 案例库 + 阈值配置）
```

### 反馈链路（三级反哺，中期后实现原型）



1. 人工复核结果 → 存入案例库

2. 案例库统计 → 辅助调整门控阈值

3. 标准库更新 → 必须人工审核后才生效（防污染）

## 三、核心技术机制

### 1. 感知层：WinCLIP 零样本异常检测



* 原理：用正常样本的 CLIP patch 特征构建记忆库（80 张 × 196 patch = 15,680 个特征）→ 测试图每个 patch 与记忆库算最大余弦相似度 → 相似度低即异常 → 异常分数 = 1 - 最大相似度

* **零样本、无训练**：只建特征库，不调任何模型参数

### 2. 门控路由：阈值判定



* 阈值 = 正常样本异常分数的**中位数 + 1.5×MAD**（开题实测 = 0.2243）

* 换产时重新采集 10-20 张正常样本 → 重新标定阈值（辅助标定 + 人工微调）

### 3. 认知层：VLM + RAG + 引用校验



* 缺陷裁剪图 → VLM 生成自然语言描述

* 描述 → RAG 检索标准片段（返回引用 ID + 标准号 + 页码）

* VLM 结构化输出（结论 + 描述 + ref\_ids + 建议）

* 后处理一致性校验：检查每个引用 ID 是否在检索结果中


  * 全部通过 → 正常展示（可溯源）

  * 存在编造 ID → 标红 "引用待核验"，降级为展示原始标准片段 + 人工选择

* 设计理念：**不追求零幻觉，追求错误可识别**

### 4. 知识库底座



* 标准片段库：基于 GB/T 34528-2017《金属材料 表面缺陷目视检测导则》，每条分配唯一引用 ID（如 `GB34528-P07-S4` = 标准号 + 页码 + 片段序号）
