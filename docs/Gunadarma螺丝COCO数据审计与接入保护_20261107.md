## 3. 分区污染风险

包内Train有21张对应本项目原测试分区，另17张对应原校准分区（`validation`）。若直接按新压缩包的Train训练，会造成旧评估图回流。

300张中有81张的原图已进入项目全局或产品专属评估封存；新增副本必须继承其排除状态。仍保留原1545张全局封存和300张产品专属封存，不把81个副本算成81个新独立测试样本。

另外，正常框面积中位数约占整图45.08%，缺陷框约3.15%。图像检查显示前者多框住整颗螺丝，后者多指局部缺陷。不能把这两类框都当作整件裁剪框直接训练质量分类器，否则输入处理本身就随标签变化。框标注可保留作后续定位研究资料，当前未据此训练或声称定位精度。

归档README标示Public Domain；与已有MVTec图像对应后，后续使用仍应核对、保留原始数据出处和条款，不能仅凭导出页面的许可文字替代来源核查。

## 4. 本轮实际完成的系统改动

1. 新增只读COCO审计工具：检查归档路径、大小、标注引用、图片尺寸、类别、框及重复，不自动建立质量模型。
2. 登记300条已核对的图像副本对应关系，文件为`results/data_intake/known_image_derivatives.json`。登记只表达来源身份，不授予质量标签、正常参考批准或自动归档资格。
3. 产品接入读取全局、各产品评估封存及副本对应。已封存图片即使改名、换产品或使用本次已登记的缩放压缩版本，也不能导入建库、训练、校准、资格检查或反馈用途；允许仅作为测试资料保存。
4. 同一已确认来源图的不同版本不能跨分区或使用冲突标签，同分区同标签按重复处理。
5. 建库开始、实际提取特征及应用候选时再次检查。导入后才被封存的图片，也不能继续用于旧候选发布。
6. 人工反馈的批准与后续迭代复用相同排除规则，防止已封存图的已知副本回灌。

线上仅识别**已登记、已核对的对应关系**，不是任意缩放、旋转、裁剪或重编码都能自动识别。未审计的其他派生版本仍需先做来源匹配与去重；不宣称已解决所有近重复泄漏。
