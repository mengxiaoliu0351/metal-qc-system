# M2螺杆细节改进与分布诊断

日期：2026-11-07。本轮已完成裁剪诊断、六个细节候选、六种固定分数融合及正常图分区诊断。**两轮后续方案都未通过历史回归，不发布、不接入自动归档。** 原线上模型、螺丝统一入口及螺杆转复核规则保留。

## 1. 为什么继续做这轮实验

螺丝入口统一解决“用户只选择一次检测对象”，不等于各视图的质量判断已经通过验证。当前M2螺杆仍缺少可启用的质量模型：V2在400张留出图上准确率95.25%，但在998张官方Test历史回归上正常误报17.20%。不能用前一组成绩遮蔽后一组失败。

本轮检查发现：旧预处理把细长螺杆补边为224×224方图，部分图的连通区域只截到螺杆片段。针对这两个现象新增细节基线，没有修改已冻结的旧预处理或原始标签。

## 2. 数据和选择规则

沿用V2的920张有标签训练图与400张校准图。检查它们没有进入全局封存清单，没有将测试图用于本轮质量模型拟合或阈值选择。其余200、400、998张都在前两轮查看过，**本轮全部称为历史回归；没有新增盲测**。第6节的事后分区诊断另行使用历史数据，只作分布分析，不用于质量模型发布。来源没有实物编号，仍只能保证图像分区，不能证明不同实物独立。

V3新增两种输入：细节HOG；细节HOG＋原有冻结CLIP特征。每种配固定C=0.01、0.1、1，共六个有标签轻量分类候选。新区域处理连接相邻暗色片段，保留96×256细长视图，灰度对比度处理后提取方向梯度；原CLIP特征不重新训练主干。它不是正常样本单独建库或零样本方案。

选择继续使用V2的校准规则：先检查召回≥93%、正常误报≤8%，再优先更低误报、更高召回及更强正则。选择只读取校准图，未选择历史测试成绩最好的一栏。选中`detail_hog_clip_c1`，下阈值0.202602。

新区域提议在200／400／998张上的成功率分别为97.50%／94.00%／99.10%。400张中有23张正常和1张缺陷未找到新区域；998张中有8张正常和1张缺陷未找到。提议失败时离线评估保留零细节特征及原CLIP分支，仍计入全部分数统计；实际作业不能据此自动判断正常，必须复核。提议成功率不是框正确率，也不是未知视图拒绝率。

## 4. 裁剪诊断能说明什么

固定按像素哈希选取各错误类型前六张，形成原图／V2裁图／新细节图对照，未按新方法是否预测正确挑图：

![历史错误与裁剪对照](../results/experiments/m2_body_quality_v3_detail/crop_audit.png)

将“旧框高度小于新框70%”作为截短线索，998张历史回归中有4张，都属于V2原本已判对的缺陷；86张正常误报中没有这一线索。因此裁剪截短确实存在，但**不能据此断言它是旧误报的原因**。没有检测框真值，本轮也不能宣称定位精度已经提高。

## 5. 融合对照：没有用旧测试挑权重

在看到V3失败后，另冻结V4开发协议：V2分数和V3分数按细节权重0、0.1、0.25、0.5、0.75、1做六个固定混合。仍只使用400张校准图选权重与阈值。

校准规则最终选中权重1，即完全采用V3分数，历史结果与V3相同，再次被否决。没有为了让998张通过而改选其他权重。该对照是事后开发研究，不是新的独立验证，也不计为第二次独立成功或失败证据。

## 6. 正常图分区诊断

为检查校准正常图是否覆盖历史Test的外观分布，取200张校准正常图及500张历史Test正常图，预测“图片属于哪个来源分区”。固定C=0.01，五折图像级折外预测，每折单独拟合缩放器。

| 诊断输入 | 分区识别折外AUROC | 分区识别平衡准确率 |
| --- | ---: | ---: |
| 旧裁剪框宽、高、中心位置 | 0.88167 | 82.70% |
| 原冻结CLIP图像特征 | 0.99987 | 98.90% |

这是**来源分区可区分性，不是正常／缺陷检测准确率**。结果支持两批正常图的输入分布存在明显差异、校准代表性需要改善。它没有证明差异具体由照明、背景、裁剪、实物形态中的哪一个因素造成；实物身份未知，以上也不是实物独立的统计推断。

## 7. 当前决定与下一步

本轮不发布质量模型，不更改自动处置权限，不把研究图片伪装成人工核验反馈。保持原V2报告候选禁用、螺杆转例外复核；保留1545张全局评估封存。新的表面外观参考仍不自动成为正常质量标签。

下一轮先解决数据覆盖与评估代表性，停止仅凭某组高准确率决定版本：

1. 补充尚未用于当前模型开发、具有明确正常／缺陷标签的螺丝数据，保留来源、原始文件和许可。不同型号或来源明确登记在同一个螺丝族下，不让操作者手工切换。
2. 先检查与MVTec AD、MVTec Screws、M2及候选数据之间的重复，识别旋转、增强和派生裁图。网络转载图不能直接当作新的独立来源。
3. 按原件／拍摄组划分训练、代表性校准和最终封存；同一原图派生的所有增强必须同组。没有实物编号时披露图像级分区的限制。
4. 代表性校准应包含多种拍摄条件，最终封存之前固定方法与门槛。对于只在历史回归上调整的方法，继续标记开发结果，不能恢复“新盲测”称谓。
5. 质量模型通过评估后，再独立验证族级视图匹配、灰区分析、自动归档错误率与抽查，再决定可自动处理的范围。

2026-11-07后续已审计用户下载的[Gunadarma University Object Detection Screw](https://universe.roboflow.com/gunadarma-university-oo4uc/object-detection-screw) v2：300张全部与已有MVTec螺丝图高置信对应，且发布方Test只有30张正常件。该来源不作为新增独立质量数据，未导入训练；已补充已确认图像副本的封存排除保护。见 [完整数据审计与接入保护](Gunadarma螺丝COCO数据审计与接入保护_20261107.md)。其他Roboflow转载版本可能共用原图，不能按网址数累加数据量。

[Real-IAD官方配置](https://github.com/Tencent/AnomalyDetection_Real-IAD/blob/main/experiments/RealIAD-full/config.yaml)的30类中没有独立螺丝类，不把它直接列为本轮螺丝质量扩充。[CAD-SD作者说明](https://github.com/IshidaKengo/Co-occurrence-Anomaly-Detection-Screw-Dataset)包含螺杆＋螺母组合的划痕、涂漆和装配异常，可作未来相关任务，不能替代M2单件螺杆缺陷的同条件验证；数据许可仍需核对。
