# M2螺杆误报改进V2：扩充训练、明暗增强与新留出验证

版本：`m2-body-quality-v2-robust`。本轮结果：**未通过全部门槛，仅展示报告，不启用试检**。

## 1. 本轮针对的问题

V1在200张资格检查图上正常误报率为3%，在998张官方Test主测试图上升至14.6%，有62张正常件进入高风险区。它不具备自动归档资格。分数分布变化是已观察到的现象，具体由光照、背景、形态或其他采集因素造成尚未确定。

本轮只研究两个可控改动：补充未参与V1开发的有标签训练图，以及对训练裁图做固定明暗增强。没有更改来源标签、没有用三类外观审核图冒充正常件，也没有训练CLIP主干或调用VLM。

## 2. 先固定分区，再提取特征和选择候选

M2 BODY原Train的1120张预留图，以固定种子按像素哈希排序，预先分为400张新测试、200张新资格检查和520张补充训练。所有新留出图均未进入本轮训练或阈值拟合。

| 本轮用途 | 正常 | 缺陷 | 来源及边界 |
| --- | ---: | ---: | --- |
| 判别训练 | 420 | 500 | V1训练400张＋原预留520张 |
| 校准与候选选择 | 200 | 200 | V1校准和已查看的旧资格集；全部属开发数据 |
| 新资格检查 | 100 | 100 | 原预留图；不拟合，仅作否决检查 |
| 新封存测试 | 200 | 200 | 原预留图；模型固定后评价 |
| 历史回归 | 500 | 498 | V1已查看的官方Test主测试；不是新盲测 |
| 异视图对照 | 50 | 50 | 旧HEAD历史对照；不是新厂家 |

正常局部库、BODY/HEAD视图中心和范围门槛沿用V1冻结参数，来源为原80张正常参考及既有HEAD参考。新增400张测试图加入全局封存，和V1官方Test1000张一并禁止通过换产品名称回流训练。原有300张产品专属封存也保留。来源没有实物身份，只能保证图像分区，不能证明不同实物、厂家或产线独立。

**新400张来自发布方Train，而不是新采集域。** 因此它们只能说明同一来源预留数据上的前瞻表现；历史官方Test回归继续单独作门槛，不允许拿容易的新留出成绩遮蔽旧失败。

## 3. 固定候选和选择规则

- 共六个候选：原图／明暗增强两种训练方式，各配C=0.01、0.1、1.0的Logistic Regression。使用同一冻结CLIP和原BODY区域处理。
- 增强在固定裁剪补边后进行，亮度系数为0.7和1.3，几何与质量标签不变；每张原图的训练总权重保持1。2760张训练视图仍只来自920张原图，不能称为2760个独立样本。
- 校准目标先满足缺陷召回≥93%、正常误报≤8%，再按误报较少、召回较高、正则更强和原图优先的固定顺序选择。不可行时按校准平衡准确率回退，并披露未满足校准目标。
- 资格检查、新400张测试和旧998张回归都不参与选择模型或调整阈值。旧测试如今是回归，不能在改进后称为再次盲测。

本轮校准选中 `photometric_c0p1`：C=0.1，训练方式=固定明暗增强。判定下阈值0.270181，上阈值0.520586。模型分数不是实际合格概率。

## 6. 发布判定与网站

门槛沿用V1：新资格检查、新封存测试和历史回归均要求缺陷召回≥90%、正常误报≤10%、视图通过率≥95%；历史HEAD排除率≥95%。服务器发布脚本会独立复核这些数值，不能只修改报告的允许标记来跳过失败。

本轮判定：**未通过全部门槛，仅展示报告，不启用试检**。 否决项：历史998张回归检查未达标。

网站入口：[产品接入](https://metalqc.online/#products) → 螺丝族 → “M2螺杆质量验证”。页面同时展示新400张对照、旧998张回归和V1完整失败结果。未达标时上传与样例试检都被服务端拒绝。通过也仅是研究试检：必须核验、不归档、不创建训练反馈、不解除正式产品的自动处置暂停。

## 8. 事后校准诊断，仅供下一轮研究，不发布

在查看本轮最终结果后，另比较了不同校准召回目标。这是事后开发探索，不能计为新的独立测试，也没有改变V2模型文件、部署阈值或试检权限。

将校准召回目标从93%改为91%时，校准集给出的候选阈值约为0.4043。在已查看的旧998张图上回放，正常误报为9.80%（49/500），缺陷召回90.56%（451/498）；在已查看的400张图上回放，正常误报3.00%，缺陷召回93.00%。这些数字仅支持继续研究阈值取舍与校准覆盖，不能据此证明新版本已经泛化通过。

下一轮应先固定召回与误报的业务取舍，补充具有代表性的正常校准样本，并用新的采集批次或来源验证。不能从多个事后探索结果里挑一个点，就替代独立验证或将V2失败改成成功。探索回执为`.preview/family-20261106/body-v2-threshold-exploration.json`。

公网图片访问验收采用HTTP Range核对PNG头，服务端仍先校验完整文件哈希；六次试检请求均返回409。一次完整大图下载曾出现读超时，本轮不声称公网大图下载性能已完成验收。123项Python回归检查通过，真实报告脚本渲染通过；未开展完整浏览器视觉验收。
