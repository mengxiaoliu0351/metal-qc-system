# 产品族库建设目标与实施路线

目标确认：2026-11-06。本文件定义后续建设方向，不把规划列为已完成功能。

## 当前执行边界（2026-11-07更新）

用户确认：保持主线，不做无用扩展，达到阶段目标即收敛。主线仍是“一次选择产品族 → 自动匹配适用参考 → 检测与明确结果处理 → 例外和抽查复核 → 经批准、独立评估的迭代”。

- 当前阶段以已通过验收的统一单图／后台批次、灰区分析、复核、PDF及追溯为稳定演示基线。螺杆质量候选未通过、头部自动处置暂停的边界保留。
- V3细节改进和V4融合未通过历史回归，研究在此收敛。后续模型改动须由可复现的新误判或有效的新质量数据触发；旧Test不再承担反复调参后“证明提高”的任务。
- 新数据先查原始出处与重叠，再决定下载和接入；只有能补充外观／采集条件且有明确质量标签的资料，才推进质量验证。Gunadarma的300张已确认副本不能当作新增覆盖。
- 每次改进只设一个具体目标：减少漏检／误报、降低复核量、缩短耗时或消除实际故障。先做小规模可复现对照，收益不明确或旧能力退步时保留原版本，避免无目标扩展模型、页面和产品种类。
- 下一次发布质量候选前，固定数据分区与验收条件；通过后再接入自动处置，保留回滚。不将选择性复核一致率、演示成功或大量拒判包装成检测准确率。

## 当前小目标

先建设一个螺丝产品族库，覆盖多种结构、尺寸、角度和合理采集条件。用户只选择“螺丝族”，系统自动寻找相关参考，输出正常、疑似缺陷或不确定；不要求用户按每个型号切换配置。

库内可按外观结构、视图和采集条件组织参考组。参考组与型号不必一一对应，相近型号能否共组由评估决定。共享视觉编码器，必要时保留轻量分组判别头及配套校准，避免为每个型号复制完整模型。

## 后续扩展目标

| 产品族 | 族内覆盖对象示例 | 库和版本的管理单位 |
| --- | --- | --- |
| 螺丝族，当前优先 | 不同槽型、头型、尺寸、视图 | 螺丝族统一参考库及其版本 |
| 螺母族，后续 | 不同外形、规格、表面处理 | 螺母族统一参考库及其版本 |
| 网格族，后续 | 不同网孔结构、尺寸、纹理 | 网格族统一参考库及其版本 |

这些是目标覆盖范围，不表示目前已采集、建库或验证。不同产品族共享系统框架和可复用的视觉能力，各自维护参考、适用范围、阈值和评估版本。

## 与原系统主线的连接

选择产品族 → 必要时定位、裁剪和对齐零件 → 族内参考自动匹配 → 本地评分与热力图 → 风险门控 → 灰区VLM与知识检索 → 合格的自动处理／不确定与抽查复核 → 批准样本进入候选训练和校准 → 留出评价 → 应用或回滚。

产品族库扩展服务于检测效率、质量和维护成本。原双链路、例外复核、周期抽查、报告与版本追溯继续保留。研究试检与正式自动处理资格分开，未通过评估的族或版本不能因入口统一而自动获得归档权限。

## 数据应区分的几个概念

| 信息 | 用途 |
| --- | --- |
| 产品族，例如螺丝 | 用户选择的检测对象和库的归属 |
| 型号／外观变体 | 记录覆盖种类，支持按种类留出评价；不强制独立建库 |
| 视图／采集条件 | 帮助参考匹配，检验角度、光照和背景变化 |
| 实物／采集批次编号，来源提供时 | 防止同一实物的相似照片跨训练和评估分区 |
| 质量标签及其依据 | 区分来源确认的正常、缺陷和未核验；类型标注不能充当正常标签 |

族内参考分组与实物去重分组是两个概念，不能共用一个含义不清的编号。没有实物身份时披露边界，不编造身份或检验员结论。

## 实施顺序

1. 将当前写死为螺丝实验的入口、路径和版本选择整理为可配置的产品族框架，先只启用螺丝族。
2. 整理带明确外观类别的螺丝图片，首批以3～5种外观结构为范围；保留来源、使用许可、视图和质量标签依据。只有类型或目标框标注的图片先用于定位和外观覆盖，不默认作为正常件建库。
3. 补充定位、裁剪与对齐。首批验收以单件清晰图为主；复杂背景、多零件图片需要先验证定位效果，不能把其他产品直接判为螺丝缺陷。
4. 建立结构化参考总库，自动匹配相关参考；遇到不适用、质量不足或证据不明确的图片输出不确定。
5. 训练和校准后，分别评价已覆盖类型换环境、留出的外观类型／来源。每种类型单独统计正常误报、缺陷漏检及不确定比例，不用大类别掩盖小类别问题。
6. 螺丝族达到阶段要求后，再按同一框架接入螺母族、网格族。族之间独立评估和发布，避免一个族的更新影响其他族。

## 第一阶段验收建议

- 对覆盖范围内、有两类质量标签的类型，初步以准确率及缺陷召回均达到85%左右、正常误报不超过15%作为研发目标；这是待验证目标，不是已达到的性能或工业放行标准。
- 只有正常件的类型，只评价误报和适用性，不宣称其缺陷检出能力通过。
- 同时报告可判定覆盖率和不确定比例，不能通过大量拒判虚增准确率。
- 保留按类型、视图及来源划分的训练／校准／留出清单；已用于评估的图片不得经反馈回流训练。
- 用户完成一次产品族选择后，不需要为每张图片手动选择已覆盖型号或参考组。
