# 头部辅助评分接入验收

## 实际更新

- 活动头部评分版本：`head_expanded_20261108`。CLIP主干、正常局部记忆库、族内参考路由和另外三个检测配置保持原样。
- 新评分下阈值为0.3852999190、上阈值为0.6795244568，均来自原开发校准规则，未根据测试成绩事后调整。
- 原头部暂停保留，另为新模型的准确文件指纹增加暂停记录。安装先写暂停，再切换模型；新版本低风险、灰区和高风险都进入复核，不自动归档正常或隔离缺陷。
- 修复导入产品迭代的标签兼容问题：读取特征缓存中的已审计来源标签，不再用MVTec的`good`目录约定猜测`normal`文件夹的标签。缺失或无效来源标签直接报错。
- 新版迭代基准保留1320张训练、200张校准、200张历史资格图及80张原正常参考的分区。新增920张只缓存了整图特征，其未计算的局部异常分数明确保存为缺失值并带可用性标志，限定整图判别模式使用，未伪造为0。

| 同一536张官方Test历史回归 | 原评分 | 当前接入评分 |

上表是离线本地二分类历史对照，不含参考拒判、VLM或人工最终结论。固定上一轮统一入口路由后，529张已判定图的准确率为94.52%，另7张保持拒判；这一数字同样是离线分数回放。此次没有再次通过公网重放全部536张，因此不将它写作新增完整网站质量测试。

候选仍漏掉25张缺陷，原族级200张中还有2张正常件进入候选高风险区。二分类改善不等于自动处置资格通过。原研究报告的否决／权限字段保留，本次另按“辅助评分更新、全部人工复核”的范围发布。
