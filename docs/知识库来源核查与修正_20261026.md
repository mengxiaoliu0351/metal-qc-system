# 知识库来源核查与修正

本轮答辩准备检查发现，原代码 `src/cognition/rag.py` 将 GB/T 34528-2017 误写为“金属材料表面缺陷目视检测导则”，并将项目编写的说明附上未经核实的页码和尺寸限值。

国家标准全文公开系统的官方目录显示，该编号对应“气瓶集束装置充装规定”，不支持原代码所述金属表面检测内容：
https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=3045A64326436924B5E7C7E3E3C0E93D

这属于知识来源错误，不能仅靠模型引用 ID 校验解决。引用 ID 存在，只能证明模型引用了本次提供的条目，不能证明条目是真实国标原文。

## 已完成修正

- 移除原错误编号下的条文、伪页码和未经证实的尺寸、照度等限值。
- 使用明确标记为项目自编教学示例的质检知识卡。知识卡只描述观察、核验与留痕流程，没有国标原文属性。
- 按产品附加官方目录记录，只有编号、名称和官方链接，不声称已接入标准全文。
- VLM、附图助手和报告说明材料来源；单张无标尺图像不得量化真实尺寸或深度，不得据未接入的条文判定是否符合国标。
- 导出历史含旧编号的报告时提示其引用已经停用，原始检测记录保留以便追溯。
- PPT 更正为“知识检索与引用校验”，将正式原文接入与适用性评测列入结题目标。

## 答辩建议口径

“目前已完成 RAG 知识检索和引用 ID 校验的应用流程。教学知识卡与官方目录分开显示，标准全文与适用性评测作为结题任务。我们不把模型能引用一个 ID 等同于条文真实或质量已符合国标。”

旧开题或历史实验材料如仍写有该错误标准名，应按本说明更正，不继续作为实测标准依据引用。
