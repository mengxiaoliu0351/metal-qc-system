# 自动归档、灰区分析与周期抽查

2026-11-03 版本。本文描述软件作业状态；不连接产线放行、报废或返工执行器。

## 检测与归档

1. 先做图像质量和产品适用性初筛，运行本地感知，保存整图分数与热力图。任何输入、模型或适用性异常都建立人工任务，不自动判为正常。
2. 每产品的 `t_low`、`t_high` 仅用于低风险、灰区、高风险路由。低、高风险不调 VLM；通过配套模型与更严格的自动处置门槛后，分别保存“系统正常”或“疑似缺陷隔离”。靠近自动处置边界的结果转人工。
3. 灰区调用 VLM 与知识检索。AI 返回结构化结论、缺陷类型、位置描述和引用 ID。引用 ID 必须来自本次检索结果。只有图像质量、产品适用性、模型版本检查通过，且下表条件同时满足时才自动归档：

| 灰区结果 | 自动处理条件 | 不满足时 |
| --- | --- | --- |
| 系统正常 | 分数位于灰区靠近低风险端的前 25%；VLM 明确给出“合格/正常”，类型为“正常”，有图像描述和有效引用 ID；该产品自动正常门槛通过 | 转人工复核 |
| 疑似缺陷 | 分数位于灰区靠近高风险端的后 50%；VLM 明确给出“不合格”，缺陷类型属于系统允许的划痕、弯曲、色差、裂纹、凸起或凹陷，有图像描述和有效引用 ID；该产品自动隔离门槛通过 | 转人工复核 |
| 不确定或异常 | VLM 返回“需复核”、结论与分数位置不一致、无有效引用、处理失败或产品检查不通过 | 转人工复核 |

上表的 25%/50% 是本原型的保守工程规则，**不是经过独立校准的准确率或概率保证**。引用校验只验证 ID 属于本次材料，不验证标准条款的真实性、内容或适用性；教学知识卡和官方标准目录也不是标准原文。灰区自动“疑似缺陷”只创建软件隔离记录。

每条记录分别保存原始本地评分、VLM 分析、作业规则判断、自动归档状态和后续人工真实标签。未自动分类的灰区不计作系统判对。

## 周期抽查与人工闭环

- 在“质效分析 → 作业策略”选择每日或每周，以及目标抽查比例（5%～100%，默认 10%）。每条自动归档记录按图像内容、产品、模型版本及周期稳定随机选择；同一周期重复上传同图不会改变选择。小批量实际比例可能偏离目标，不承诺每期固定件数。
- 抽查任务与不确定、边界、图像异常、处理失败等例外一起进入“人工复核”。可用“抽查任务”或“灰区待核验”筛选；质效分析页展示本期自动记录、抽查入队、已核验及发现误判数量。
- 人工核对原图、热力图和 AI 证据后填写真实标签、人员与依据。人工标签不覆盖系统原始判断；“结果基本正确/有误”普通反馈也不等于真实标签。
- 人工确认自动结果误判时，暂停该产品当前模型版本的自动处置。经明确批准的标签才可进入候选训练或阈值校准；冻结回归/测试图和重复图按已有规则隔离。候选通过评估后仍需人工应用，可回滚。

## 评估口径

质效分析按产品列出灰区自动正常、自动疑似缺陷、不确定转人工、已核验漏检和误隔离。抽查和例外产生的已核验样本有选择偏差，不能直接当独立准确率；仍需采集新增且未用于调规则的样本，分别验证正常件误隔离、缺陷漏检、自动覆盖率、VLM 调用量及真实人工耗时。历史中期答辩的 88 张冻结公开图没有测量本规则的灰区 VLM 最终判定，不能引用其 94.32% 作为更新后的系统准确率。
