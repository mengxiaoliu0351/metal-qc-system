# 螺丝族匹配边界改进与独立留出

## 本轮目标

继续解决用户只选择“螺丝族”后，系统自动寻找适用参考的问题。原版在473张留出裁图中，把17张尚未支持的短杆螺丝错误吸收到已支持外观；这会影响后续选择检测配置，因此优先修复。

本轮不增加质量标签、不把网络图当正常件、不更新四个正式产品的质检模型。质量判断仍需有可信正常／缺陷标签及适用范围验证。

## 改进方式

保留人工审核通过的24张参考：亮面8张、黑色4张、机螺丝12张。另从原始训练分区的其他六种类别中，各选12张、每类来自不同原图，共72张**类型排除参考**。

排除参考只使用作者提供的类别标注，用来回答“是否更像未覆盖类型”。它们没有人工质量核验，不进入正常记忆库，也不表示新增六类已具备质量检测能力。全部向量与类别保存在同一个参考文件，用户仍只选择产品族。

### 第二版失败，完整保留

第二版允许重新选择相似度门槛。新增301张图中，未覆盖类型误接受从11降到2，但旧473张回归中，多接受了1张已覆盖类别的匹配错误。它未通过预先写明的“不增加已覆盖错误”条件，因此没有上线。记录在 `results/experiments/screw_appearance_v2/`。

### 第三版采用保守规则

第三版保持原版相似度门槛0.94442048和类别差值门槛0，只增加“已覆盖参考的相似度不低于类型排除参考”的条件。不会因降低旧门槛，把原来不确定的图改成接受。

排除比较门槛仅在444张校准图上选择；校准阶段同时限制已覆盖正确接受率下降不超过2个百分点。应用检查继续要求新增评价、旧回归不增加已覆盖匹配错误、不明显降低正确接受覆盖、减少未覆盖误接受，并检查其他产品对照。

## 网站和工程验证

网站“产品接入 → 产品族库 → 已审核外观 · 自动匹配”已支持排除参考比较，展示最相似已审核参考及最接近的未覆盖类型参考，并分别说明来源。页面将新增评价、旧473张和前轮301张明确分开。

106项自动化测试通过。新增304张全部经本地真实HTTP接口重跑，全部与冻结离线决策一致；输入质量拒绝0张，最大相似度误差约3.58×10⁻⁷。公网另做选定样例验收，不能把它说成公网全量304张重跑。

两轮605张评价图已写入外观封存清单。它们即使原始分区名为train、后来做了资料审核，也不能进入新参考拟合；发布器还按原图保护，阻止同原图其他裁图绕过。资料审核仍可独立保存，不解除封存。

正式产品配置、正常记忆库、原两来源质量模型、风险阈值和自动处置资格没有改变。仅更新外观参考版本，保留前一版指针以便回退。
