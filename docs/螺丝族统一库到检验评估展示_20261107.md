# 螺丝族：统一参考库、检验、复核与评估展示

**2026-11-08界面调整：** 用户明确要求螺丝族作为一个检测类型，不单独建设展示工作台。因此质效分析里的大块三页签展示已撤下。当前日常入口为[工件检验](https://metalqc.online/#detect)，检测类型仅并列显示螺母、螺丝、金属网格；螺丝参考匹配在后台完成，结果中技术说明默认折叠。

原“产品接入”入口改名“研发设置”，详细库资料和研究评估保持默认折叠，汇总CSV也从该折叠区下载。没有删除数据、模型、历史记录或评估依据。下文三页签布局与展示步骤属于2026-11-07的历史实现记录，不再代表当前用户界面；其中的样本数量、真实实验结果和接口验收记录仍保留。

本轮交付的是现有螺丝族能力的完整展示链，不扩数据、不替换质量模型，不将未通过的候选包装成可用检测能力。

入口：[质效分析中的螺丝族展示](https://metalqc.online/#dashboard)。顶部新增三个页签：“统一库与范围”“检测与评估”“完整流程演示”。[直接进入螺丝检验](https://metalqc.online/#family)沿用现有工件检验页，并自动选择螺丝，没有新增第二个检测界面。

## 统一库的实际组织

用户选择一次螺丝，内部使用一个族级参考目录、共享CLIP ViT-B/16编码器，按采集视图组织参考、判别头及阈值。目前复用两套质量配置，不宣称所有外观已经合成一个质量模型。

| 内容 | 当前实际状态 |
| --- | --- |
| 自动视图分流 | 螺丝近景、M2头部、M2螺杆，共3组 |
| 已绑定质量配置 | 螺丝近景、M2头部，共2套；头部自动处置暂停 |
| 外观匹配参考 | 亮面、黑色、机螺丝；24张正向参考及72张排除参考 |
| 外观资料目录 | 9类、3,049张裁图，来源没有正常／缺陷标签 |
| 螺杆、一字槽头部质量候选 | 门槛未通过；保持研究结果，不接入自动质量判断 |

页面另外展示每个视图的正常建库、拟合、校准、评价样本数量。正常参考图可能同时用于判别头拟合，各列不可简单相加。M2螺杆V2复用V1的80张正常参考，不因V2协议未重复列出这些图片就显示为0。

## 结果如何展示

“检测与评估”分别展示视图分流、外观检索和正常／缺陷判别。不会把接受子集的准确率、拒判覆盖或演示通过率当作缺陷准确率，也不合并不同分区算一个总准确率。

| 质量配置／研究版本 | 评价范围 | 准确率 | 缺陷召回 | 误报／漏检 |
| --- | --- | ---: | ---: | ---: |
| 螺丝近景当前配置 | 40张历史留出 | 90.00% | 90.00% | 1／3 |
| M2头部当前配置 | 536张官方封存图，网站批次回放 | 91.60% | 89.96% | 17／28 |
| M2螺杆V2候选 | 原Train预留400张 | 95.25% | 95.00% | 9／10 |
| M2螺杆V2候选 | 998张历史官方Test回归 | 88.38% | 93.98% | 86／30 |
| CSEM一字槽候选 | 38个实物，主光照501 | 92.11% | 84.21% | 0／3 |

以上是原有真实实验结果的可追溯汇总，本轮没有重新训练或测出新的质量提升。它们不含VLM及人工纠错。螺杆两分区应同时解读；CSEM另外两种光照是相同实物的配对照片，不能增加独立实物数。

各项同时提供混淆矩阵、评价口径、状态和CSV导出。准确率、召回、误报率先与原始混淆计数核对；有矛盾则停止展示。当前模型数组与阈值也需与成绩绑定一致；变化后标记为研究或历史结果，不冒充当前成绩。外观参考和视图参考分别核对版本。

## 建议按这个顺序展示

1. **展示库。** 在“统一库与范围”介绍三种采集视图、正常库和判别头如何建立，以及外观资料为何不等于质量真值。
2. **展示检测。** 进入工件检验，选择“螺丝 · 自动匹配视图”，载入近景固定试件，展示匹配参考、分数、热力图及处理状态。
3. **展示不同视图。** 用M2头部说明同一入口如何选择另一检测配置；用螺杆或未验证外观说明系统会保留不确定性，转入复核，不强行输出合格。
4. **展示追溯。** 在“完整流程演示”的实际验收记录中打开复核入口和PDF。核验人应根据可靠依据自行确认，系统不代填人工标签。
5. **展示迭代与结果。** 进入已有模型迭代页查看候选评估、应用和回滚机制，再回到本页用混淆矩阵解释准确率、误报、漏检及未发布原因。

模型迭代能力继续受原批准门槛和评估排除约束。固定演示图不能因打开复核入口就自动变成训练真值；演示记录不计正式作业效率。来源标签回放与检验员核验仍是不同证据。

## 实际验收

- 本机与公网均实际完成5类单图接口：近景、M2头部、M2螺杆、未验证外观及其他产品。每例生成可追溯记录与有效PDF。
- 本机与公网均完成一个3视图混合后台批次。用户选择一次螺丝，内部自动分流，逐项保留处理结果和PDF。
- 展示页可直接打开上述真实公网单图记录和PDF；回执校验当前核心流程源码，后续代码变化会标识为历史验收。
- 只读HTTP验收覆盖静态资源、四组建库分区、五组质量结果、CSV、版本绑定和五份PDF。演示不写人工质量标签，不清除M2头部暂停或启用螺杆候选。
- 最终159项Python自动化测试通过；新增展示结果核对、版本变化识别及验收回执约束，Node检查覆盖页签切换、失败候选展示、转义、异常状态和复核记录链接。
- Edge视觉检查未完成：computer-use工具无法可靠确认当前浏览器网址而停止交互。前端交互逻辑、数据转义、异常状态和记录入口通过Node检查；不将其称为浏览器截图或视觉验收。

回执在`.preview/screw-delivery-20261107/`，包括`local-flow-acceptance.json`、`cloud-flow-acceptance.json`、本机／云端混合批次与展示页验收JSON。以上是流程和元数据验收，不是新增独立缺陷精度测试。
