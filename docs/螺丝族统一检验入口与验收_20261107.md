# 螺丝族统一检验入口与验收

日期：2026-11-07。最终入口：[工件检验](https://metalqc.online/#detect)。产品族检验已合并到“工件检验”的“检测对象”选择中，不再保留并列操作入口。旧`#family`链接自动跳到工件检验并选择螺丝；“产品接入”页保留内部配置和研发资料。

更新：单图和批次均只显示螺母、螺丝、金属网格等检测对象。M2头部不再作为独立操作选项，属于螺丝对象内自动匹配的视图。后台仍保存各视图的质量模型与阈值；合并入口不意味着将不同模型强行混为一个。批次中的`family:screw`只是内部标识，不是要求用户选择另一种类型。

## 本轮实现

用户只选一次“螺丝 · 自动匹配视图”，上传清晰单件图片，不需要手动挑选头部、螺杆或具体检测配方。系统先检查图像，再匹配适用来源／视图，最后决定接入已有检测流程还是转例外复核。

| 自动匹配结果 | 实际处理 |
| --- | --- |
| 螺丝近景视图 | 调用现有`screw`产品流程，保留本地评分、热力图、灰区VLM＋RAG、自动作业门槛和抽查 |
| M2头部俯视 | 调用现有M2头部产品流程；该产品原有自动处置暂停继续生效 |
| M2螺杆侧视 | 质量候选仍未通过历史回归，保存待核验记录；不运行被否决的质量模型、不输出正常／缺陷 |
| 外观资料可匹配但无质量验证 | 不能因为外观审核通过就当成正常件，保存例外复核任务 |
| 未覆盖、匹配不确定或图像质量不足 | 不猜测正常／缺陷，不调用VLM强行下结论，保存待核验记录 |

所有有效输入均可进入检验档案，待核验结果使用原人工复核功能。PDF增加产品族、匹配视图和分流参考版本。未绑定质量模型的记录可保存人工最终标签，但页面禁用迭代批准，后端也拒绝批准其进入已有产品模型，避免把新外观或螺杆样本回灌到头部模型。

本轮是**统一作业入口及统一适用视图库**。质量引擎仍复用既有两套产品配置和正常记忆库，不能说已经合并为一个共用质量模型。统一参考组代表拍摄来源／视图，不是已验证的型号识别。

## 分流依据与回归结果

共享现有CLIP编码器，输入完整图片补边到224像素。三个已覆盖视图各使用80张正常参考建立视图中心；外观审核24张、类型排除72张及10张其他产品图只作适用性排除，不生成质量标签。

校准175张，其中已覆盖视图120张、未验证外观和其他产品55张。按预先固定规则设置相似度和视图间差值门槛；如果更接近排除参考，则不选择质量模型。验证不满足每个视图覆盖率或未知输入误接受门槛时，禁止启用作业分流。

| 验证分组 | 图数 | 接受且分流正确 | 不确定／拒绝 | 错误接受 |
| --- | ---: | ---: | ---: | ---: |
| 螺丝近景视图 | 40 | 38 | 2 | 0 |
| M2头部俯视 | 40 | 38 | 2 | 0 |
| M2螺杆侧视 | 40 | 39 | 1 | 0 |
| 未验证外观及其他产品 | 65 | 不适用 | 65 | 0 |

已覆盖视图接受率115/120＝95.83%，被接受的115张全部分流正确。**这是选取检测流程的结果，不是缺陷检测准确率。** 上述图片来自已有公开数据的历史分区，用于分流集成回归；不是新增厂家、实物级或产线盲测。没有证据保证所有陌生输入都能拒绝。

185张分流验证图加入全局封存，和此前1400张质量测试图合并去重后共1545张；原300张产品专属封存继续保留。不能通过换产品名将这些图片回流训练。

## 页面使用与当前限制

1. 进入“工件检验”，将“检测对象”选为“螺丝 · 自动匹配视图”，上传单件图并执行检测。批量图片使用原“批次检验”，选择同一个螺丝对象。
2. 查看匹配视图参考、原图、可用时的热力图、处置结果和VLM调用情况。参考图仅说明视图，不是上传件合格证明。
3. 待复核记录可点击“处理人工复核”，所有已保存结果可导出PDF或回看检验档案。
4. 正式上传按原作业门槛决定自动归档、隔离、抽查或人工复核。固定五类演示样例标记为流程演示，转核验且不计入日常质效；不提交虚构人工标签。

原外观匹配、BODY质量实验、两来源质量研究和外观资料审核留在“产品接入”页的研发资料折叠区；这些是内部资料管理，不再与普通工件检验并列。

合并后，螺丝对象复用原可恢复后台批次：每张自动匹配，刷新浏览器后可继续查看；任务冻结分流库、外观排除版本及所有可能使用的质量配置，版本变更会暂停，配置暂时不可用也会暂停并保留已完成项。质量封存评估仍需明确具体检测配置，不能把混合视图作业直接当作一个模型的质量盲测。多件自动定位、全部型号覆盖和新的外观质量验证仍未实现。

分流复用同一编码器实例，但适用性补边图与原产品输入不同，已匹配输入可能需要两次CLIP前向。不宣称族级分流没有计算开销。页面统计本族正式作业的自动处理比例、人工比例、VLM调用率及中位／P95总耗时；没有核验真值时不显示检测准确率。选择性核验的一致性也不等于独立测试准确率。

## 验收与复现

冻结协议、参考与报告：`results/experiments/screw_family_router_v1/`。本机和公网五类HTTP演示均应覆盖“近景、头部、螺杆、未验证外观、其他产品”，并检查每条记录的PDF可下载；不据五张演示声称完整系统质量性能。

```powershell
$env:PYTHONPATH='src'
python -m experiments.family_router prepare
python -m experiments.family_router extract
python -m experiments.family_router fit
python -m experiments.family_router evaluate
python -m experiments.family_router references
python -m experiments.family_inspection_acceptance --base http://127.0.0.1:8000 --output .preview/family-20261107/local-acceptance.json
```

已有分流模型或报告时拒绝重拟合、重测覆盖。135项Python检查通过；增加了对象选项合并、头部配方隐藏、混合视图批次及恢复字段、配置不可用暂停和质量评估用途隔离。脚本还核对单图／批次共用对象定义、旧链接跳转，以及更换上传图片后不能误用旧演示样例。
