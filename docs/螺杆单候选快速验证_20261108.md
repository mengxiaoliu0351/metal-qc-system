# 螺杆单候选快速验证

日期：2026-11-08。结论：未改善，开发阶段提前停止，未读取资格／测试／历史回归特征，未修改线上配置。

本轮回应统一螺丝入口中的螺杆质量缺口，只检验一个改动：保持V2冻结CLIP特征、训练图片、固定明暗增强和校准目标，将线性判别改为固定C=0.1的RBF判别。未做参数搜索，没有根据旧Test成绩挑选阈值。

沿用920张来源训练图和400张开发校准图，完全复用特征缓存。来源仍是M2公开OK／NG标签，未伪装为人工反馈；未使用新数据、VLM或新增网站入口。

固定开发目标为缺陷召回≥93%、正常误报≤8%。新候选两项均未达到，立即停止，不再读取历史评估分区或扩大参数搜索。上述数字是开发校准结果，不是新的测试准确率。

这项结果只说明该固定非线性改动没有改善目前开发分布，不能证明所有非线性方法都无效，也不能解释分布差异的物理原因。原V2失败记录、螺杆转复核状态和头部暂停保留。

3项新增检查覆盖可移植预测与原拟合模型一致、训练不读留出特征、开发失败即停止。原8个活动配置／策略／封存保护文件哈希一致。
