# 质量检测主线与后续数据接入

## 主线

系统最终要让用户选择产品族后，自动定位／识别适用外观、找到合适参考，可靠地给出缺陷检测辅助意见，明确结果自动处理，不确定与抽查转人工，并以有质量依据的核验结果驱动校准和版本评估。

外观匹配解决“该找谁作参考”，不能代替“零件是否合格”。现有外观图不因为颜色、完整、清晰或用户认可而成为正常件质量真值。新外观尚无质量验证时，保持“质量判断未提供”。原四产品的检测配置和已有暂停状态继续独立管理。

当前优先顺序：修复误匹配与验证边界 → 扩充有可信标签的螺丝质量数据 → 验证定位和完整作业流程。先不扩展泛用聊天、新页面或更多无质量标签的网络图片。

## 质量数据接入必须形成的证据

1. 保存作者来源、版本、许可、文件哈希、原始标签含义和拍摄视图；实际样本数以归档审计为准。
2. 在建库、拟合与校准前固定正常参考／训练／校准／资格检查／测试分区，并记录图片和实物分组依据。没有实物编号时明确披露。
3. 按产品族中的视图和外观记录适用范围。不得因螺丝族识别成功，直接套用M2头部分类器到螺杆或其他结构。
4. 使用来源正常样本建库，质量分类仅使用有质量依据的训练标签；保留旧方法与新方法在同一留出集上的完整对照。
5. 报告准确率、缺陷召回、正常误报、漏检和拒判覆盖，同时核对网站实际接口、灰区调用、人工任务量与延迟。不能只报接受子集的准确率。
6. 新质量版本必须通过独立评估后才允许接入检测；是否自动处置还需单独检查。外观参考变更不自动修改正常库或质检阈值。

## 当前仍缺少的能力

新三种外观尚无经验证的质量检测能力；多件照片自动定位尚未实现；真实厂家、真实产线和不同实物泛化尚无充分证据。本轮类型排除实验只推进适用性判断，不能把该缺口包装成已经解决。

已完成V3细节特征与V4固定分数融合。V3在400张历史留出图上准确率97.50%，但998张历史回归准确率84.07%、缺陷召回79.72%；V4按校准选择退化为同一候选，均不发布。正常图分区识别显示校准与历史Test的输入特征明显可区分，具体采集因素尚未确定。下一步优先审计新的明确质量标签来源及校准覆盖，不再把不同分区中的最高准确率作为发布依据。见 [完整对照、裁剪图与下一批数据要求](M2螺杆细节改进与分布诊断_20261107.md)。

## 2026-11-07：新螺丝来源小规模独立验证

已下载并按作者MD5完整核验[CSEM-MISD v0.2.0](https://zenodo.org/records/7410513)螺丝原包。70个有缺陷掩码的实物中，固定18个拟合、14个校准、38个官方Test；另442个未标注实物不当作正常件。三个固定光照按同一实物配对，不将114张测试照片当作114个独立样本。

仅比较正常CLIP局部参考库与冻结CLIP特征的轻量监督判别。校准选中的监督方案三种光照均为92.11%准确率、84.21%缺陷召回、0/19正常误报；每种光照漏掉同三个缺陷实物，未达事先固定的85%召回门槛，未发布。正常库准确率63.16%～73.68%的失败结果同时保留。现有三视图路由器对该新外观114张图全部拒绝套用旧质量模型，按现有规则应转复核；该项是离线适用性审计，不能称作缺陷识别通过。

本轮扩充了可追溯实验依据，没有增加网站已验证质量能力。旧模型和参考指针不变；本机已封存官方Test实物全部108种光照身份。测试失败后不降低门槛，也不重复用同一Test做新盲测。详见[完整结果、漏检解释与复现](CSEM新螺丝来源独立验证_20261107.md)。
